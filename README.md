## 🧠 How Stenwatch Works (Simple Version)

Stenwatch uses something called a **“pipeline”** – think of it as an assembly line for information.

1. **Collect** – It gathers data about all known CVEs from global databases.
2. **Filter** – It removes anything that is not relevant to your industry, location, or technology stack.
3. **Prioritise** – It assigns a risk score based on real-world exploitation, attack patterns, and published government warnings.
4. **Explain** – It writes a short summary in plain English for each remaining item.

The result is a clean dashboard with a handful of urgent items, each with a clear “why” and a suggested next step.
